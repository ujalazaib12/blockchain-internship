Day 5 Task: Meet Ethereum
Accounts: Wallet vs Contract
Ethereum has two types of accounts. A wallet account, also called an externally owned account, is controlled by a person using a private key. This is what you create in MetaMask. A contract account is controlled by code instead of a person. It only does something when a wallet account or another contract sends it a transaction. So a wallet is like a person, and a contract is like a robot that follows the instructions written into it.
Gas and Transactions
Every action on Ethereum, like sending ETH or interacting with a smart contract, requires computing power from the network. Gas is the fee you pay for that computing power. It is paid in ETH. More complex actions cost more gas because they need more computation. A transaction is any action you sign and send to the network, like transferring ETH or calling a function on a contract.
The EVM
EVM stands for Ethereum Virtual Machine. It is the engine that runs on every node and actually executes smart contract code the same exact way, everywhere. This is what makes Ethereum consistent, since every node runs the same code and reaches the same result, keeping everyone in agreement.
What is a Smart Contract
A smart contract is just code stored on the blockchain that runs automatically when certain conditions are met. It cannot be changed once deployed, and it does not need a middleman to enforce it. For example, a smart contract could automatically send you an NFT the moment you pay a certain amount of ETH, no company needed to process it manually.
