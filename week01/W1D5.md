One Page Summary

Blockchain is a shared, distributed ledger maintained by many independent computers (nodes) instead of one central authority. It solves the double-spend problem by having the whole network agree on the order of transactions through consensus. Data is secured using hashing, which creates a unique fingerprint for information, and blocks are linked by referencing the previous block's hash, making the chain tamper-evident. Users control accounts through a public/private key pair, where the private key signs transactions to prove ownership and authenticity. Networks reach agreement using consensus mechanisms like Proof of Work, where miners solve computational puzzles, or Proof of Stake, where validators stake coins as collateral. A fork happens when the chain splits, either briefly by accident or intentionally through a rule change. Ethereum expands on Bitcoin's model by supporting smart contracts, self-executing code stored on-chain that runs through the Ethereum Virtual Machine (EVM). Every action on Ethereum costs gas, paid in ETH, and accounts are either wallets (controlled by people) or contracts (controlled by code). Tokens are custom assets built using smart contracts on top of ETH, the network's native currency.
